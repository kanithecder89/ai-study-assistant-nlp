# AI Study Assistant 

A Python-based NLP tool that analyzes study documents and generates summaries and quizzes automatically.

##  Features
- Extracts key points from PDF, PPT, DOCX
- Automatic text summarization
- Quiz generation from content
- Keyword and concept extraction

## Tech Stack
Python, NLP

## Purpose
Helps students reduce study time by converting lengthy documents into concise notes.
